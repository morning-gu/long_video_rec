# 算法引入路线图：M6–M8 规划

> 基线：M1–M5 已交付（四段漏斗 + LLM 增强 + 实时回流 + 评测体系）。
> 当前指标：最终 HR@10 = 0.198（纯热门 8.6×）；单通道 SASRec 0.250 / ItemCF 0.155 /
> 双塔 0.115 / 热门 0.023；精排 = DeepFM + γ·SASRec 分数级融合。
> 环境约束：本机 2 核 CPU（无 GPU）+ qwen3.7-plus API（预算无上限）+ 海报 URL 可被
> VLM 读取；无剧情文本、无多行为标签（完播/时长/弃剧）、无曝光日志。

**GPU** = 需要你的强算力机器；**✗** = 数据不可支撑，不做（见 §4）。

## 2. 环境能力矩阵（训练资源结论）

| 类别 | 当前 2 核 CPU | 强 CPU 机器 | GPU 机器 |
|---|---|---|---|
| LightGCN / 蒸馏粗排 / DIN / MMoE(评分头) / DPP / RQ-VAE / TIGER-lite | ✅ 全部可训（分钟~小时级） | ✅ 更快 | ✅ |
| ML-25M/32M 全量重训（双塔/SASRec/LightGCN 放大） | ❌（小时→天级，勉强） | ✅（小时级） | ✅（推荐） |
| VLM/LLM 管线（画像/查询/模拟器/重排） | ✅ 纯 API，无训练 | ✅ | ✅ |
| LLM LoRA 微调（TALLRec/CoLLM） | ❌ | ❌ | ✅（≥8GB 显存跑 1.5B LoRA；24GB 舒适 7B） |
| DiffKG/DimeRec 扩散类 | ❌ | ❌（理论可行实际过慢） | ✅ |

**结论**：M6、M7 全部可在当前环境完成（CPU 训练 + API 增强）；M8 需要你的强算力机器
（GPU 优先；纯规模化部分强 CPU 也够）。

## 3. 里程碑规划

### M6：内容理解与图结构（当前环境，预计 1–2 天）

**目标**：补齐内容侧（当前推荐完全基于行为协同，海报零利用）与图结构两条腿。

1. **LightGCN 召回通道**：二部图 2–3 层传播，CPU 训练分钟级；接入配额融合（替换或并行热门通道）。
2. **VLM 海报画像管线**（`scripts/enrich_vlm.py`，复用海报增强的节流/断点续跑/429 退避模式）：
   qwen-vl 读海报 URL → 结构化 JSON（题材标签/年代/基调/视觉风格/一句话描述，白名单约束防幻觉）
   → text-embedding → 语义召回通道（Faiss ANN）；API 调用约 3.8k 次，节流 1–2s/次 ≈ 1–2 小时。
3. **内容特征进精排**：题材匹配度、基调匹配（用户历史基调直方图 × 电影基调）为 dense 特征。
4. **DPP 替换 MMR**（顺手，毫秒级）。
5. **评测更新**：新通道 sanity + 漏斗报告 + 多样性/覆盖率（预期 ILAD ↑、覆盖率 ↑）。

**验收**：LightGCN HR@10 ≥ 0.10；语义召回 HR@10 ≥ 0.05（显著高于热门 0.023）；
最终链路 HR@10 不降且 ILAD/覆盖率提升；报告页新增通道行。
**风险**：VLM 标签质量参差 → 白名单 + 人工抽查 50 部；海报 URL 被 VLM 服务拒绝访问 → 下载到本地转 base64 兜底。

### M7：生成式检索与蒸馏（当前环境，预计 2–3 天）

**目标**：落地研究文档最前沿的"语义 ID + 生成式检索"趋势，并把粗排做成真模型。

1. **RQ-VAE 语义 ID**：对（双塔 item 向量 ⊕ M6 内容向量）联合量化 → 2–3 层 × 256 码本。
2. **TIGER-lite 生成式召回**：历史语义 ID 序列 → 自回归生成下一个 item 的码字（beam search +
   合法码约束解码防幻觉）；CPU 训练（模型 ≈ SASRec 规模，预计 1–3 小时）。
3. **冷启动演示（杀手级演示点）**：虚构"新片上架"→ VLM 生成其内容向量 → 编码语义 ID →
   立即进入召回，零交互数据（文档 01 趋势一的核心卖点）。
4. **蒸馏粗排**：teacher = 精排融合分，student = 轻量双塔打分；在漏斗候选分布上蒸馏，
   替换"通道截断"临时方案（兑现文档 03 文档 2 §3.2 的目标一致性议题）。
5. **LLM 用户画像卡**：观影历史 → 口味画像（偏好类型/基调/年代），UI 展示 + 进 LLM rerank 提示词。
6. **MMoE 双头精排**（可选）：喜好分类 + 评分回归，演示多任务结构（如实标注非真实多行为）。

**验收**：TIGER-lite HR@10 进入 0.15–0.30 区间（对标 SASRec）；冷启动新片被召回（人工验证）；
蒸馏粗排使 粗排→精排 链路 HR 不低于截断方案；评测报告新增 TIGER 通道与蒸馏前后对比。
**风险**：TIGER-lite 效果不及 SASRec（生成式检索在小数据集上常见）→ 保留为独立通道演示趋势，
如实标注对比结果（延续 Ferrari Dacrema 的诚实评测传统）。

### M8：规模化与 LLM-native（需强算力机器，GPU 优先）

**目标**：验证架构的规模扩展性 + 落地 LLM 微调，对应文档 03 的下一代叙事。

1. **数据升级 ML-25M/32M**：全链路重训（双塔 dim 64→128、SASRec 加深、LightGCN、TIGER），
   Faiss 换 HNSW（兑现 D1 预留）；检验指标随规模的变化曲线（scaling 叙事）。
2. **TALLRec/CoLLM 式 LoRA 微调**：本地 Qwen2.5-1.5B（或 7B）+ LoRA 指令微调
   （输入=用户历史+候选，输出=排序/偏好），对照 API prompt-only LLM rerank 的零样本基线
   ——直接回答"微调 vs 提示词"这个研究问题（文档 03 趋势 7）。
3. **LLM 用户模拟器在线评估**（API，可提前做）：模拟用户对 Top-K 列表的点击/忽略反馈 →
   模拟 CTR/NDCG 对比各策略；明确标注 simulation 性质（文档 01 §5.3）。
4. **多轮对话式推荐**：偏好澄清（"想更轻松一点还是更烧脑？"）→ 更新检索。
5. **（可选研究项）DiffKG/DimeRec 扩散类模型**：GPU 训练，作为对照研究点。
6. **在线化工程**：强机器上重拾 500ms 时延目标、并发压测、缓存策略。

**验收**：25M 规模全链路指标 ≥ 1M 规模（预期）；LoRA ranker 优于零样本 LLM rerank（AUC/HR）；
模拟在线评估报告；演示脚本 v2。
**风险**：25M 训练时间不可控 → 先跑双塔+ItemCF 保底；LoRA 效果不及 prompt → 如实对比（同样可能）。

## 5. 执行建议

- M6 立即可启动（无环境依赖）；M7 依赖 M6 的内容向量；M8 等你的强算力机器就位。
- 每个里程碑沿用既有纪律：sanity 评测先行 → 通道接入 → 漏斗报告更新 → 演示脚本同步；
  所有新增通道必须通过"打赢热门基线"的 Ferrari Dacrema 检验才进主链路。
