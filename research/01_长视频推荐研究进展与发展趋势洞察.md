# 长视频个性化推荐：从评分预测、多阶段排序到语义化与长期价值优化

## 摘要

长视频推荐与短视频、电商或新闻推荐的关键差异不在“模型更大”，而在消费成本高、行为稀疏、剧集结构复杂、家庭观看场景突出、优化目标更接近留存与长期满意度。过去二十年中，该领域经历了四条主线：评分与矩阵分解、隐式反馈与深度排序、图/多模态/多任务结构、以及 2023 年以来的 LLM 与生成式推荐。当前最确定的趋势不是 LLM 取代传统推荐系统，而是 **语义 ID、生成式检索、多模态内容理解、长期价值优化与工业级多阶段系统架构的融合**。

## 1. 研究问题

- **RQ1**：长视频推荐算法从早期研究到 2026 年经历了哪些主要技术演进？
- **RQ2**：长视频场景有哪些不同于短视频、电商或新闻推荐的特有约束？
- **RQ3**：未来 3-5 年，长视频推荐最重要的研究方向是什么？

核心判断：**长视频推荐正在从“在有限候选集上学习个性化排序”转向“用语义、多模态和长期行为模型理解用户，同时用多阶段工业系统解决成本、时延和业务目标”。**

## 2. 方法与证据边界

本报告基于公开学术论文、工业论文、Netflix Tech Blog、arXiv 预印本和 RecSys/KDD/WWW/CIKM/ICDM 等主流会议文献整理，检索视角包括：

1. 经典推荐算法与电影数据基础；
2. 序列推荐、图推荐、多任务排序模型；
3. 流媒体与视频平台工业系统；
4. LLM、生成式推荐、多模态与对话式推荐；
5. 数据集、长视频结构与用户行为。

证据边界：本文不是 PRISMA 式系统综述，且工业系统披露有限；Netflix、YouTube、腾讯视频等公开论文只能代表可披露部分，不能等同于各平台完整系统。对 Disney+、爱奇艺、腾讯视频等平台，公开材料覆盖不均，本文只使用可核验来源。

## 3. 技术脉络：四个阶段

### 3.1 第一阶段：评分预测与矩阵分解

长视频推荐最早的核心形式是电影评分预测。MovieLens 提供了电影评分基准，使协同过滤、矩阵分解和邻居方法可以在统一数据集上比较 [4]。Netflix Prize 将电影推荐转化为显式评分预测问题，推动矩阵分解成为当时主流 [2][3]。Koren 等人的矩阵分解方法将用户和电影映射到同一隐向量空间，通过向量内积预测偏好 [2]。

Netflix 系统论文进一步说明，真实工业系统并非只依赖单一评分模型，而是由个性化排名、搜索、推荐、首页布局和 A/B 实验共同组成 [1]。这一阶段的贡献是明确：推荐系统可以被形式化为可学习的偏好建模问题。但局限也很明显：显式评分不等价于观看行为；电影消费频次低；RMSE 与真实推荐效果之间的对应关系不稳定；Netflix Prize 和 MovieLens 均缺少曝光、点击、播放、完播、弃剧、订阅和流失信号 [4][5]。

### 3.2 第二阶段：隐式反馈、序列模型与深度排序

流媒体平台兴起后，研究对象转向隐式行为：曝光、点击、开始播放、播放时长、完播、重看、跳过、暂停、弃剧和续看。Hu 等人的隐式反馈协同过滤为“观看行为而非评分”的目标函数奠定了基础 [6]。

YouTube 工业论文是这一阶段的重要转折。Covington 等人将推荐系统拆分为 candidate generation 和 ranking，使系统可以在海量视频库中先召回少量候选，再用更复杂的模型排序 [7]。2019 年 YouTube 的多任务排序系统进一步把 MMoE、多行为目标和位置偏差纳入线上排序 [8]。腾讯视频 PLE 论文则在 10 亿级样本上展示多任务学习对点击、观看时长等视频推荐目标的价值 [9]。这些工作共同确立了“召回-粗排-精排-重排”的工业主流架构。

模型层面，Wide & Deep、DeepFM 和 Deep Interest Network 解决了特征记忆与泛化、低阶特征交互和动态兴趣建模问题 [10][11][12]。序列推荐模型则更直接刻画兴趣演化：GRU4Rec 将 RNN 用于 session-based recommendation [13]；SASRec 使用 self-attention 捕捉长期序列 [14]；BERT4Rec 采用双向 Transformer 和 masked item prediction 建模序列依赖 [15]。

不过，序列模型在长视频中的效果受数据密度和 item 粒度限制。一个用户可能一年只看几十部电影，却可能连续观看同一部剧的十几集。如果将电影和剧集都视为同一粒度 item，会丢失剧集内部的强结构信息。

### 3.3 第三阶段：图结构、知识图谱与多模态推荐

第三阶段的核心是利用结构化关系缓解稀疏性和冷启动。NGCF 通过图神经网络传播协同信号 [16]；LightGCN 简化 GCN 设计并提升推荐效果 [17]；KGAT 将知识图谱中的高阶关系引入推荐 [18]。电影、剧集、演员、导演、类型、IP、世界观和剧情元素天然构成知识图谱，因此图与知识图谱方法对长视频有三重价值：

1. **缓解稀疏性**：新电影缺乏交互时，可通过演员、类型、IP、导演、主题等关系获得先验；
2. **提升可解释性**：例如“因为你看过同一导演/题材作品”比纯 embedding 更易解释；
3. **支持跨内容泛化**：电影、剧集、纪录片、综艺之间的关系可通过图结构共享。

多模态推荐进一步利用海报、预告片、封面、字幕、音频、视觉风格和用户评论。Movie Recommendation with Poster Attention 证明海报视觉特征与文本元数据融合可提升电影推荐 [19]；RAG-VisualRec 提供了视觉-文本增强电影推荐的开放资源 [20]。这些工作把 item 从随机 ID embedding 推向内容对象，使推荐系统能理解“电影为什么被喜欢”。

### 3.4 第四阶段：LLM、生成式推荐与语义 ID

2023 年以后，LLM-based recommendation 成为重要新方向。相关 survey 系统总结了 LLM 在推荐中的角色：特征增强、排序器、生成式推荐器 [21][22][23]。

具体形态包括：

1. **LLM 作为语义增强器**：将剧情、评论、字幕、海报、风格描述转化为语义表示，用于新片冷启动；
2. **LLM 作为零样本或少样本排序器**：Hou 等人发现 LLM 可根据用户历史对候选物品排序，但效果受候选集大小、排序策略和 prompt 设计影响 [24]；
3. **LLM 作为可指令化推荐器**：TALLRec 展示轻量微调 LLM 适应推荐任务的路径 [25]；Recommendation as Instruction Following 将推荐视为指令跟随任务 [26]；
4. **生成式检索与语义 ID**：TIGER 将 item 转为 Semantic IDs，用 Transformer 生成式检索替代传统判别式排序 [27]；GPTRec 探索自回归序列推荐 [28]；
5. **代理化推荐**：AgentCF 将用户和物品建模为语言智能体，通过协作学习捕捉交互关系 [29]。

对电影场景，LLM 的价值尤其突出。Sun 等人的用户研究直接评估了 LLM 作为对话式电影推荐器的表现 [30]；DUALRec 将序列模型与语言模型结合用于电影推荐 [31]；LLM 也可用于预测新片热门程度，为冷启动推荐提供先验 [32]。

但该方向代价明确：生成结果可能重复、幻觉出不存在的内容、难以精确约束版权库范围，且线上推理成本远高于双塔召回和 ANN 检索。因此更现实的路线是：**LLM 与语义 ID 增强传统推荐系统，而不是完全替代它们。**

## 4. 长视频场景的特殊约束

### 4.1 消费成本高，反馈稀疏

短视频消费成本低、反馈频繁；电影和电视剧消费成本高。长视频中的每次选择包含更高机会成本，曝光-点击模型不足以刻画真实偏好。开始播放、播放一半、完播、重看、连续追看、季末弃剧等信号语义不同。如果只优化点击率或播放次数，系统可能偏向标题党、封面诱人或低质量内容。

### 4.2 剧集结构与追剧行为

电视剧推荐不能只把剧集当作一个 item。用户可能处于未看、第一集、第三季、季末、弃剧边缘、重看阶段或等待每周更新。Trouleau 等人对 binge watching 的建模说明，长视频消费存在明显“再看一集”模式 [33]。因此需要建模：

- episode-level preference；
- season-level state；
- release schedule；
- sequential commitment；
- drop-off risk。

### 4.3 家庭、多用户与共看场景

Smart TV 推荐研究强调，电视推荐面对的是家庭账户、共同观看、多成员偏好和客厅情境 [34]。同一账户可能混合多位家庭成员，观看记录混合后会产生错误画像。未来需要从个人画像扩展到 household-level preference、co-viewing detection、profile separation 和 group recommendation。

### 4.4 界面与视觉个性化

Netflix 的 artwork personalization 工作说明，推荐不仅决定推荐哪部作品，也决定用什么封面呈现作品 [35]。同一电影对不同用户展示不同封面，可显著影响点击和观看。推荐系统不仅排序 item，还排序 item 的展示方式：封面、文案、推荐理由、榜单、页面布局和横向内容排布。

### 4.5 业务目标不只是播放时长

流媒体平台最终关心订阅、留存、内容投资回报和用户满意度。播放时长是重要代理指标，但过度优化时长可能导致低质量成瘾式推荐。Netflix 早期系统论文已强调推荐系统的业务价值体现在降低取消订阅和提升会员生命周期价值 [1]。因此长视频推荐需要多目标优化：短期观看、长期留存、多样性、满意度、新内容冷启动、小众作品公平曝光和用户疲劳控制。

## 5. 数据基础与评估挑战

### 5.1 数据集的演进与不足

MovieLens 和 Netflix Prize 是电影推荐研究的基石 [3][4]，但它们以显式评分为核心，缺少观看时长、完播、弃剧、曝光和页面上下文。隐式反馈方法 [6]、Trakt.tv 这类 episode-level 观看记录 [36]、IMDb 元数据 [37]、TV 上下文偏好数据 [38] 和剧集多模态标注 [39] 提供了补足方向，但规模、公开程度和行为偏差各不相同。

### 5.2 离线-在线错位

传统离线指标包括 RMSE、Recall、NDCG、Hit Rate 和 MRR。这些指标有助于模型比较，但存在三个问题：

1. 离线数据来自过去曝光日志，而曝光本身受旧推荐系统影响；
2. 负样本和目标样本构造方式会改变结论 [40]；
3. 长视频核心指标是长期行为，如续订、追完一部剧、减少流失和满意度，难以在静态数据集上完整评估。

Hidasi 和 Czapp 对 RecSys 离线评估缺陷的分析指出，许多研究存在 dataset-task mismatch、过度预处理、时间信息泄漏和负采样不当 [41]。Bauer 等人对 2017-2022 年 57 篇推荐系统评估研究的系统综述发现，offline evaluation 主导，MovieLens/Amazon 数据集过度集中，beyond-accuracy 指标很少被评估 [46]。Ferrari Dacrema 等人的复现研究更尖锐：在 12 个 neural recommenders 中，11 个被简单、调参好的非神经 baseline 超过，说明部分离线“进步”来自弱 baseline [47]。

因此，长视频推荐研究需要区分三层目标：预测历史交互、影响即时观看行为、改变长期满意度与留存。三者并不天然一致。

### 5.3 A/B 实验仍不可替代，但不充分

Netflix 的实验平台和 interleaving 工作说明在线实验是工业推荐迭代的核心 [42][43]。Kohavi 等人的 A/B testing 实践指南进一步强调 guardrail metrics、实验有效性和长期效果评估中的常见陷阱 [48]。A/B test 能直接观察用户行为，但局限同样明显：实验周期可能不足以观察长期留存；指标之间可能冲突；用户组存在异质性；推荐会改变未来行为并形成反馈循环。反事实评估和 off-policy evaluation 提供了从历史日志估计新策略的路径 [49]，Aouali 等人则指出 reward-optimizing recommenders 的 offline proxy 与 online reward 相关性不足，simulation-based evaluation 可能更接近真实目标 [50]。

### 5.4 偏差、公平性与 beyond-accuracy

长视频平台天然存在 popularity bias。Abdollahpouri 等人系统梳理了 popularity bias 的成因、危害和缓解方法，指出它会造成曝光与机会不公平并强化 filter bubble [51]。Singh 和 Joachims 将排名中的曝光视为需要公平分配的资源，为首页推荐位、搜索排序和海报横幅曝光提供了理论框架 [52]。推荐系统手册进一步将 diversity、serendipity、novelty、fairness 和 user-centric evaluation 纳入完整评估维度 [53]。

对长视频平台而言，多样性不是道德附加项，而是业务需求：用户长期只看同类型内容会产生疲劳；小众内容需要公平曝光；内容投资需要通过推荐系统得到回报；多样性有助于长期留存；用户需要可探索的内容空间。

## 6. 工业系统架构

典型长视频推荐系统是多阶段漏斗：

1. **召回**：从海量内容库中快速筛出数千或数万候选，常用协同过滤、双塔、图召回、多模态召回和语义检索；
2. **粗排**：用轻量模型减少进入精排的候选；
3. **精排**：用深度模型预测点击、播放、完播、时长、续看、收藏、评分和负反馈；
4. **重排**：考虑多样性、重复内容、页面布局、业务约束和封面选择；
5. **上下文决策**：根据设备、时间、家庭成员、观看历史和当前页面动态调整结果。

YouTube 的两阶段架构 [7]、多任务排序系统 [8]、Netflix 系统论文 [1] 和腾讯视频 PLE [9] 都体现了这一分层思想。其核心原因是工程约束：全库精排不可行，系统必须在效果、时延、成本和可维护性之间权衡。

Netflix 近期对个性化基础模型和大规模生成式推荐的探索 [44][45] 显示，系统可能从“每个页面、每个任务一个模型”走向“共享用户与内容表示，再接任务头”的架构。优势包括减少重复建模、提高跨任务迁移、更好处理稀疏行为和支持新任务快速上线；代价是模型体积、训练成本、可解释性、故障隔离和目标冲突。

## 7. 未来趋势

### 趋势一：语义 ID 与生成式检索

传统推荐依赖随机初始化 item ID embedding，新片缺乏交互时 embedding 学不到有效表示。Semantic ID 可将电影、剧集、题材、演员、风格和叙事结构映射到可生成语义空间，使冷启动更友好。TIGER [27] 和 GPTRec [28] 已展示潜力；Netflix 也在探索大规模生成式推荐 [45]。关键问题包括：避免重复、保证 item 存在于版权库、处理实时目录更新、控制推理成本、与传统召回融合以及评估真实增益。

### 趋势二：LLM 与传统推荐系统互补

LLM 的最大价值是理解自然语言偏好和内容语义，而不是直接替代全库召回。用户可以说“我想看类似某电影但节奏更快的片”，这需要语义比较和偏好推断。Sun 等人的电影对话推荐用户研究 [30]、DUALRec [31] 和 AgentCF [29] 共同指向一个趋势：**传统模型负责行为信号，LLM 负责语义理解、自然语言交互和解释。**

### 趋势三：多模态内容理解将成为主要建模对象

未来系统可能同时理解预告片、海报、封面、字幕、音频、视频片段、剧情、导演风格、演员表现、用户评论和社交讨论。推荐系统将从“记住哪些用户看过哪些电影”变成“理解电影为什么被喜欢”。

### 趋势四：从 item-level 到 episode-level 与 season-level

电视剧推荐需要更细粒度结构建模：是否喜欢某部剧、某个角色、某条剧情线；是否在某一季流失；是否对叙事节奏疲劳；是否因每周更新保持参与；是否因季末悬念继续观看。

### 趋势五：家庭级与共同观看建模

智能电视场景需要同时建模 individual preference、household preference、co-viewing context、profile switching 和 privacy-sensitive personalization。这是一个尚未被充分解决的问题。

### 趋势六：长期价值与用户福祉纳入目标

未来目标将从短期 engagement 扩展到 long-term retention、satisfaction、perceived quality、content discovery、user agency、well-being 和 trust。仅优化播放时长可能导致过度推荐和疲劳。

### 趋势七：隐私、公平性与内容治理

长视频推荐涉及强个人偏好、家庭数据、跨设备行为和版权。未来必须处理数据最小化、跨设备追踪限制、用户可控偏好、可解释推荐、小众内容公平曝光、创作者公平性和平台透明度。

### 趋势八：效率决定新技术能否上线

LLM 和多模态模型线上成本高。真正的工程突破可能不是“模型离线效果最好”，而是模型蒸馏、离线语义 embedding、ANN 检索、缓存、级联排序、低精度推理、端侧小模型和云端-端侧协同。竞争点之一是**单位算力带来的用户价值**。

## 8. 结论

### RQ1：主要演进

长视频推荐经历了四个阶段：

1. **评分与矩阵分解**：MovieLens 与 Netflix Prize [2][3][4]；
2. **隐式反馈、深度排序与序列推荐**：YouTube、PLE、Wide & Deep、DeepFM、DIN、GRU4Rec、SASRec、BERT4Rec [6]-[15]；
3. **图、知识图谱与多模态**：NGCF、LightGCN、KGAT、Poster Attention、RAG-VisualRec [16]-[20]；
4. **LLM 与生成式推荐**：TIGER、GPTRec、AgentCF、对话式电影推荐、DUALRec [21]-[31]。

### RQ2：长视频特殊约束

行为稀疏、消费成本高、完播/弃剧/续看/重看比点击更重要、剧集具有 episode 和 season 结构、binge watching 显著、家庭与共同观看突出、展示层决策重要、业务目标更接近长期留存和订阅价值。

### RQ3：未来趋势

语义 ID 与生成式检索、LLM 与传统推荐互补、多模态内容理解、episode/season 级建模、家庭与共同观看、长期价值和福祉优化、隐私与公平性、高效推理与系统级成本控制。

## 总体判断

长视频推荐的未来不是“用 LLM 替换推荐系统”，而是形成新的分层结构：

> **传统协同过滤与序列模型继续提供高效行为信号学习；图和多模态模型提供结构化内容理解；LLM 提供语义先验、自然语言交互和解释能力；生成式检索与语义 ID 改变候选生成方式；多阶段工业系统负责把所有能力放进可服务、可实验、可审计的线上环境。**

真正的研究前沿在于这些模块如何协同，以及如何把长期用户价值、内容公平性和系统效率纳入统一目标。
