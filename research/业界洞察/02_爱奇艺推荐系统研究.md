# 爱奇艺推荐系统研究文档

> 研究问题：
> 1. 爱奇艺推荐系统的公开架构与关键算法有哪些？
> 2. 长视频场景中的召回、排序、重排、多场景 / 多目标、序列建模、LLM / 生成式推荐、冷启动、长期价值与评估如何实现？
> 3. 从公开证据看，2024—2026 年其最新方案与技术演进是什么？

## 摘要

爱奇艺推荐系统的公开披露有一个明显特点：

> **技术公开高峰集中在 2017—2023 年，尤其是 2020—2021 年的短视频推荐链路；2024—2026 年推荐系统内部算法的系统性公开明显减少。**

因此，对爱奇艺的研究必须区分：

- 可确认的公开方案；
- 公开证据不足的方向；
- 不能因为公开少就推断厂商没有做。

从可核验资料看，爱奇艺推荐系统公开架构的主线是：

```text
多路召回 / 多兴趣召回
   ↓
粗排
   ↓
精排
   ↓
多目标融合
   ↓
在线推荐
```

其公开技术关键词包括：

- 召回 + 排序；
- 多兴趣召回；
- 粗排模型优化；
- MMoE；
- 多目标排序；
- Pareto 多目标优化；
- PSO 参数搜索；
- 双 DNN 在线知识蒸馏；
- 通用排序框架。

## 1. 公开架构主线

爱奇艺早期官方资料已经说明，其推荐系统主要分为两个阶段：

1. **召回**
   - 从千万级视频库中筛出几百到几千候选；
2. **排序**
   - 对候选内容进行更精细的偏好打分。

后续公开资料显示，架构逐步演进为：

```text
用户行为 / 视频特征
   ↓
多路召回
   ↓
多兴趣召回
   ↓
粗排
   ↓
精排
   ↓
多目标融合
   ↓
展示
```

与短视频平台相比，爱奇艺主站业务具有明显的长视频特征：

- 内容生命周期更长；
- 用户决策成本更高；
- 观看周期更长；
- 会员、广告、内容运营目标更复杂；
- 单条内容的消费时间远长于短视频。

不过，爱奇艺最详细的推荐技术公开主要来自短视频推荐链路，而非主站长视频推荐，因此需要谨慎迁移。

## 2. 关键技术模块

### 2.1 多兴趣召回

爱奇艺公开材料讨论过短视频推荐中的多兴趣召回技术。

核心思想是：

- 用户兴趣不是单一的；
- 一个用户可能同时喜欢综艺、悬疑剧、喜剧、纪录片等；
- 单一用户向量容易把多个兴趣压缩成一个平均表示；
- 多兴趣召回将用户兴趣拆成多个向量或兴趣簇；
- 每个兴趣簇对应一条召回通路；
- 最终再合并候选。

这与工业推荐系统的多兴趣建模方向一致。

### 2.2 粗排

爱奇艺公开分享过短视频推荐粗排模型优化历程。

粗排的目标包括：

- 统一处理多路召回结果；
- 对候选进行初步打分；
- 降低精排计算压力；
- 提升召回和精排之间的目标一致性。

这说明爱奇艺公开链路中已经存在：

```text
召回 → 粗排 → 精排
```

的工业推荐范式。

### 2.3 多目标排序

爱奇艺在 InfoQ 等技术社区公开过短视频推荐中的多目标排序实践。

公开提到的技术包括：

1. **MMoE**
   - Multi-gate Mixture-of-Experts；
   - 多个 expert 网络共享底层表征；
   - 不同任务通过不同 gate 组合专家输出。

2. **多目标融合**
   - 对完播、互动、点击、播放时长等目标分别建模；
   - 再通过融合公式或策略生成最终排序分数。

3. **Pareto 多目标优化**
   - 在多个目标之间寻找更优平衡；
   - 避免单一目标提升导致其他目标下降。

4. **PSO 参数搜索**
   - 用粒子群算法搜索目标融合参数；
   - 降低人工调参成本。

公开材料中提到过业务收益，如人均播放时长、互动率提升。但由于缺少完整实验设置、置信区间和复现条件，这类数字应视为业务效果描述，而不是可独立复现的学术结论。

### 2.4 通用排序框架

爱奇艺公开过《通用排序框架在爱奇艺推荐的应用》。

其工程意义包括：

- 支持不同业务接入；
- 统一特征、样本、训练和 serving 链路；
- 降低新场景模型开发成本；
- 从单场景定制模型走向平台化排序能力。

这说明爱奇艺的推荐系统不仅在优化单点模型，也在建设更通用的排序基础设施。

### 2.5 双 DNN 与在线知识蒸馏

公开材料还提到过双 DNN 排序模型与在线知识蒸馏。

其目标通常包括：

- 在线或准在线更新；
- 用 teacher model 指导 student model；
- 降低复杂模型 serving 成本；
- 保持线上效果和推理效率之间的平衡。

但公开细节有限，无法判断其具体生产覆盖范围。

## 3. 2024—2026 年最新公开状态

目前没有找到爱奇艺 2024—2026 年系统性公开的推荐算法论文或完整技术博客。

公开重心更多转向：

- AI 内容生产；
- 剧本评估；
- 虚拟拍摄；
- 微短剧；
- 长短内容融合；
- 广告与商业化生态。

因此，对“爱奇艺最新推荐算法”的准确回答是：

> **公开证据不足以还原其 2024—2026 年完整推荐系统方案。可确认的公开演进仍主要停留在 2020—2023 年的多兴趣召回、粗排、多目标精排和通用排序框架方向。**

## 4. 模块级证据表

| 模块 | 公开证据强度 | 主要发现 |
|---|---:|---|
| 召回 + 排序 | 高 | 官方早期资料明确披露 |
| 多兴趣召回 | 中 | 短视频推荐中有公开讨论 |
| 粗排 | 中高 | 公开材料明确讨论粗排优化 |
| 精排 | 中高 | 有排序实践、通用排序框架、知识蒸馏材料 |
| 多目标排序 | 高 | MMoE、Pareto、PSO、多目标融合有公开证据 |
| 重排 | 低 | 未找到系统性公开方案 |
| 序列建模 | 低 | 未找到爱奇艺直接公开的完整方案 |
| LLM / 生成式推荐 | 低 | 2024—2026 公开证据不足 |
| 冷启动 | 低 | 公开证据不足 |
| 长期价值 | 低 | 公开证据不足 |
| 评估体系 | 中 | 有 AUC、完播、互动等指标描述，但完整评估体系披露不足 |

## 5. 关键局限

1. **场景偏差。** 最详细的技术公开主要来自爱奇艺随刻或短视频推荐，而非主站长视频推荐。
2. **时间断层。** 2024—2026 年公开证据不足，导致“最新方案”只能回答到公开披露边界。
3. **评估信息不完整。** 虽有 AUC、完播、互动等指标，但缺少完整 offline / online 对照、A/B test 设计、置信区间、长期指标和消融实验。
4. **缺少论文级证据。** 未找到爱奇艺 2024—2026 年在 RecSys、KDD、CIKM、WWW 等会议上的推荐系统论文。
5. **工程与算法耦合度高。** 公开材料更偏业务经验分享，难以判断模型效果来自算法、数据、特征、工程链路还是产品策略。

## 6. 结论

爱奇艺公开可确认的推荐方案是：

> **多路召回 / 多兴趣召回 + 粗排 + 多目标精排 + 通用排序框架。**

由于 2024—2026 年推荐系统细节公开不足，不能负责任地宣称爱奇艺已经采用与 Netflix、YouTube 类似的 foundation model 或 generative recommendation 主链路。
